# LuxFlow

**Браузерное расширение для управления цветовой температурой экрана и защиты зрения.**

Аналог f.lux, но работающий как браузерное расширение. Автоматически адаптирует цветовую температуру содержимого вкладок в зависимости от времени суток и геолокации.

![LuxFlow](https://img.shields.io/badge/version-1.0.0-cyan) ![License](https://img.shields.io/badge/license-MIT-blue) ![Manifest](https://img.shields.io/badge/manifest-v3-green)

## Возможности

- 🌅 **Автоматическая смена температуры** по времени суток (SunCalc + геолокация)
- 🎨 **10 визуальных эффектов**: классика, тёмная комната, голубое небо, соляная лампа и другие
- 🎬 **Кино-режим** с настраиваемой виньеткой
- 🌙 **Светлая и тёмная темы** интерфейса
- ⏸️ **Пауза на 1 час** с живым обратным отсчётом
- 🖥️ **Полноэкранный режим**: автоматическое отключение в fullscreen (YouTube и т.д.)
- 🚫 **Исключения доменов**: отключение фильтра на выбранных сайтах
- ⌨️ **Горячие клавиши**: `Alt+P` — пауза, `Alt+F` — вкл/выкл, `Alt+E` — расширение
- 📊 **Живой график температуры** на 24 часа
- 🏙️ **Автокомплит городов** (40+ городов РФ и СНГ)

## Технологии

- **Сборка**: Vite 7 + @crxjs/vite-plugin
- **Язык**: TypeScript 5 (strict mode)
- **UI**: React 19 + Tailwind CSS v4
- **Content script**: Чистый TypeScript + Shadow DOM
- **Геолокация**: SunCalc (BSD-2) + IP API
- **Manifest**: V3

## Установка (для разработки)

```bash
# Клонировать репозиторий
git clone https://github.com/graphica-online/luxflow.git
cd luxflow

# Установить зависимости
npm install

# Собрать production версию
npm run build

# Загрузить в Chrome:
# 1. Открыть chrome://extensions/
# 2. Включить "Режим разработчика"
# 3. "Загрузить распакованное" → выбрать папку dist/

# Загрузить в Яндекс.Браузер:
# 1. Открыть browser://extensions/
# 2. Включить "Режим разработчика"
# 3. "Загрузить распакованное" → выбрать папку dist/
