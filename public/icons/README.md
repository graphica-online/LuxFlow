# Icons

Здесь должны лежать иконки расширения:
- icon16.png (16×16)
- icon48.png (48×48)
- icon128.png (128×128)

## Пока (Этап 1) — заглушки

На Этапе 1 достаточно 3 однотонных PNG-файлов cyan-цвета.
Chrome покажет их в панели расширений.

Можно сгенерировать быстро в любом графическом редакторе:
- Цвет фона: #06B6D4 (cyan-500)
- Текст: `Lf` белым, шрифт без засечек

Или скачать заглушки с https://placeholder.com/16/06B6D4/ffffff
